# RideMitra MVP — Customer App v0.2

Flutter starter for a Bike + Auto + Cab ride-booking app.

## Included
- Customer home screen
- Bike / Auto / Cab selection
- Pickup and destination fields
- Google Maps integration
- Current-location permission + GPS
- Book Ride search state
- Cash / UPI placeholder

## Run
1. Install Flutter SDK.
2. From this folder run `flutter pub get`.
3. Add your Google Maps API key to Android/iOS using Google's Flutter Maps setup instructions.
4. Run `flutter run`.
